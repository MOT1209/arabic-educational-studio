# المحرك والقوالب (مجلد engine/)

## الأوامر
```
python scripts/doctor.py                                   # البيئة جاهزة؟
python engine/init_project.py <مشروع>                       # مجلدات + خطوط
python engine/example_make_script.py <مشروع>/video-01       # مثال سيناريو (انسخه وعدّله)
python engine/render_scene.py <فيديو> scene_03 --shots 2 8  # لقطات اختبار (PNG في build/)
python engine/render_scene.py <فيديو> scene_03 --render     # فيديو مشهد واحد (بوابة ج)
python engine/build.py <فيديو> lesson [--audio audio --retime] [--music m.mp3] [--workers 4]
python engine/assemble.py <فيديو> lesson                     # دمج فقط (build.py يستدعيه)
```
التصيير حتمي الزمن (`renderAt(t)` في القالب)؛ لذلك يُقسَّم المشهد على متصفحات متوازية (`--workers`) دون اختلاف في النتيجة. السرعة المرجعية: ≈ 2 ث تصيير لكل ثانية فيديو على جهاز بنواتين.

## ما يُصيَّر (`engine/capabilities.json` هو المرجع)
| حقل/نوع | السلوك |
|---|---|
| `characters` | teacher (يسار)، student طالبة (يمين، أو وسط إن حضرت inna)، inna ساحرة بشرارات (يمين) |
| `enter` | `{"inna": 0.5}` دخول بقفزات من اليمين في الثانية المحددة |
| `dialogue.emotion` | مرح، حماس، فرح، تشويق، استغراب، متردد، تشجيع (تعبير الوجه) |
| `arabic_text` | جملة السبورة (≤ 6 كلمات)، `status: wrong` بالأحمر |
| `highlight` | يلوّن **كلمة مطابقة حرفياً بتشكيلها** في جملة السبورة الحالية + `tag` وسم تحتها |
| `badge` | ✓ أو ✗ (`kind`) |
| `quiz` | سؤال + ≤ 3 خيارات (أ/ب/ج)، عدّاد 3-2-1 من `countdown_from`، كشف الصحيح عند `reveal`؛ يخفي السبورة أثناءه |
| `transition: fade` | تلاشٍ في آخر المشهد |
| الترجمة المدمجة | سطر الحوار الحالي مع اسم المتكلم أسفل الشاشة دائماً |
| وصفي فقط | `animation`، `callout`، `image`، `shape` (لا تُرسم؛ الفحص ينبّه) |

## حالة القوالب
| نوع الدرس | القالب | الحالة |
|---|---|---|
| نحو: جملة + تلوين + تصحيح + تمرين | scene_template.html | منجز ومجرَّب |
| إملاء: خطأ ← تصحيح | القالب الحالي (status + badge) لكلمة/جملة | يعمل بحدوده؛ المقارنة الجانبية مخططة |
| صرف: جذر/وزن | «حروف تنزلق إلى قالب الوزن» | مخطط |
| بلاغة: نص موثق وتفكيك صورة | «مشبّه/مشبّه به/وجه شبه» | مخطط |
| أصوات: مخرج الحرف | رسم تشريحي + صوت | مخطط |
| عمودي 9:16 | نسخة عمودية من القالب | مخطط |

## توسيع المحرك (شخصية أو نوع مرئي أو تخطيط جديد)
1. انسخ `scene_template.html` (لا تكسر القالب المجرَّب) وأضف الرسم/النوع داخل `renderAt(t)` بدالة نقية للزمن: لا `Date.now` ولا عشوائية غير مبذورة ولا انتقالات CSS.
2. أضف في `render_scene.py → build_data` تمرير الحقول الجديدة.
3. حدّث `capabilities.json` (الشخصية وموضعها وجنسها، أو النوع إلى `rendered_visuals`) والسكيما إن لزم حقل جديد؛ الفحص يقرأ القدرات تلقائياً.
4. صيّر لقطات عند لحظات الدخول والذروة والخروج وافحصها بالعين، ثم مشهداً كاملاً للاعتماد (بوابة ج).
5. أي تعديل على القالب يغيّر «بصمة المحرك»، فيعيد `build.py` تصيير كل المشاهد. هذا مقصود.
6. سجّل التغيير في `CHANGELOG.md` للمهارة.
