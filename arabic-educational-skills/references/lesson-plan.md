# خطة الدرس العامة (lesson-plan v1)

المهارة تنتج **أي درس يطلبه المستخدم**: أي مادة (لغة، نحو، إملاء، علوم، رياضيات، تاريخ، دين، مهارات حياة…) ولأي عمر.
أنت (النموذج) تكتب الخطة من الطلب؛ الكود يتحقق ويحسب التوقيت ويصيّر. درس الحروف للأطفال قالب جاهز يولّد خطة تلقائياً.

## سير العمل
1. **افهم الطلب** (سؤال واحد كل مرة، وافتراضات معقولة لما لم يُقل): الموضوع، العمر، المدة، الصيغة (16:9 / 9:16 / 1:1)، النمط، والصوت (تسجيل المستخدم أم ترجمة فقط).
2. **حلّل الدرس** (`lesson-analysis.md`): القاعدة بدقة، الأخطاء الشائعة، الأمثلة، ومصدر التحقق. المعلومات العلمية والشواهد من مصدر، لا من الذاكرة.
3. **اكتب الخطة** `lesson-plan.json` بالبنية أدناه ← `python -m studio plan validate plan.json` ← أصلح كل خطأ، وعالج التحذيرات أو اذكرها.
4. **اعرض الخطة للاعتماد** (العناوين ونص السرد)، ثم لقطات: `python -m studio plan stills plan.json --out out/` وانظر إليها بنفسك قبل عرضها.
5. **الصوت**: `python -m studio plan voice plan.json --out voice/` يعطي أسطر التسجيل بمعرّفاتها. يسجّل المستخدم كل سطر في `audio/<id>.wav|mp3|m4a|ogg`. الصوت الأطول يمدّد الكتلة ولا يُقص، وفم الشخصية يتحرك مع شدة الصوت الفعلية.
6. **التصيير**: `python -m studio plan render plan.json --out out/ [--formats 16:9,9:16] [--audio audio/]` ← MP4 + SRT لكل صيغة + فحص تقني.
7. **التسليم**: ما فُحص آلياً، ما فُحص باللقطات، ما لم يُفحص (المعنى، النطق، الدقة العلمية تحتاج مراجعاً بشرياً).

## البنية
```json
{
  "plan_version": "1.0",
  "slug": "inna",                        // اسم ملفات المخرجات (لاتيني)
  "title": "إِنَّ وَأَخَوَاتُهَا",
  "subject": "arabic_grammar",           // نص حر
  "audience": {"age_band": "preteen", "lang": "ar"},   // preschool | child | preteen | teen | adult
  "target_seconds": 120,                 // اختياري؛ تحذير إن ابتعد التقدير أكثر من 15%
  "formats": ["16:9", "9:16"],           // و"1:1"
  "style": {"theme": "chalkboard", "accent": "#FDE047"},   // classroom | chalkboard | paper | minimal | night
  "narrator": {"avatar": "letter_buddy", "avatar_letter": "ن"},   // أو "none"
  "blocks": [ ... ]
}
```
كل كتلة: `id` لاتيني فريد (اسم ملف الصوت، بلا `__`)، `type`، و`narration` (نص السرد المشكول). اختياري: `narration_after` (سرد ثانٍ بعد الأول)، `hold_seconds` (وقفة)، `cue` (بطاقة «قولوا معي» أثناء الوقفة)، `min_seconds`، `delivery: "slow"`، `caption_override`.

| النوع | الحقول | الاستعمال |
|---|---|---|
| `title` | `heading`, `subheading` | افتتاح |
| `explain` | `heading`, `text`, `bullets[]`, `highlight[]` | شرح فكرة (النقاط تظهر تباعاً مع السرد). بعنوان فقط = بطاقة انتقال |
| `term` | `term`, `definition` | مصطلح وتعريفه |
| `example` | `text`, `highlight[]`, `status` (right/wrong/neutral), `label`, `caption`, `dir`, `size: "xl"` | مثال، أو خطأ شائع مشطوب |
| `compare` | `heading`, `right{label,text,status,highlight}`, `left{…}` | قبل/بعد، صح/خطأ (`right` يظهر على اليمين أولاً) |
| `steps` | `heading`, `items[]` (≤6) | خطوات أو مراحل أو قائمة مرتبة |
| `image` | `concept`, `asset` (مسار صورة)، `caption` | صورة؛ بلا `asset` تظهر بطاقة محجوزة باسم المفهوم |
| `letter` | `letter`, `name`, `trace`, `show_forms` | حرف كبير يُرسم محيطه ثم يُعبّأ، وأشكاله |
| `word` | `word`, `highlight_letters[]` (فهارس الحروف)، `syllables[]`, `concept`/`asset` | كلمة بتلوين حرف داخلها دون كسر الاتصال |
| `say_with_me` | `text`, `repeat`, `pause_seconds`, `cue` | نموذج نطق ثم وقفة ترديد مع شريط |
| `quiz` | `question`, `options[]` (2–4)، `answer_index`, `answer_narration`, `think_seconds`, `listening` | سؤال، عدّاد تفكير، كشف الإجابة مع سرد. `listening: true` يمنع ظهور الجواب في السؤال والترجمة |
| `recap` | `heading`, `points[]` (≤5) | تلخيص |
| `outro` | `text`, `subtext` | ختام |

## قواعد الجودة
- **النص على الشاشة قصير**؛ السرد يحمل الشرح. الحد التحذيري: 140 حرفاً لـ16:9 و100 لـ9:16. اللوح يصغّر المحتوى تلقائياً إن زاد، لكن التصغير الكبير علامة على كتلة يجب تقسيمها.
- **كل نص عربي معروض مشكول** بالقدر الذي يحتاجه المتعلم؛ الفاحص يرفض الحروف الفارسية والحركتين على حرف والشدة المكررة.
- **الإيقاع حسب العمر**: الفاحص ينبّه إلى الكتلة الأطول من 20ث (preschool) أو 25 (child) أو 35 (preteen) أو 45 (teen) أو 60 (adult).
- **التفاعل للأطفال**: سؤال أو ترديد واحد على الأقل. للكبار: مثال خاطئ ثم صحيح، وسؤال تطبيقي.
- **بنية مقترحة**: خطّاف (سؤال أو خطأ شائع) ← فكرة واحدة ← أمثلة متدرجة ← خطأ وتصحيحه ← تمرين ← تلخيص.
- **التلوين** في `example` و`explain` يطابق النص حرفياً بتشكيله، وإلا يرفضه الفاحص.

## الحدود الصادقة
- الشخصية الوحيدة المنفّذة: **الحرف شخصية** (`letter_buddy`، أي حرف من 28). الشخصيات البشرية المرسومة تحتاج رسّاماً (ملف Rive لاحقاً).
- `letter.trace` يرسم **محيط** الحرف، لا ترتيب ضربات الكتابة الحقيقي.
- لا توليد صور ولا نطق آلي: الصور ملفات يقدّمها المستخدم، والصوت تسجيله.
- المحرك القديم (`engine/`، HTML) ما زال يعمل لسيناريوهات `master-script.json` ذات المعلم والطالبة.
