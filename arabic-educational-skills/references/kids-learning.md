# استوديو الأطفال: دليل سريع

`python -m studio lesson <حرف> --out dir [--profile preschool|standard] [--target ثوانٍ] [--taught "احرف سبق تعليمها"] [--ledger review.json]`

**مراحل الدرس:** تعريف ← اسم الحرف وصوته ← شكل المفرد ← أول/وسط/آخر (مع الاتصال) ← أمثلة ← حركات/سكون ← مقاطع وقراءة ← جملة ← تمرين ← تلخيص.
**حالات خاصة:** الألف لا تتصل بما بعدها (ا د ذ ر ز و وكذلك أ إ آ ؤ ة ى)؛ ألف ≠ ألف مقصورة (ى) معالَجة بمشهد مستقل؛ الشدة حرف واحد في الكتابة وحرفان في النطق والتقطيع (بَطَّة = بَطْ | طَة).
**الفحص:** الكود يتحقق أن الحرف موجود فعلاً في الموضع المدّعى وأن الشكل المعروض يطابق قاعدة الاتصال (جُرِّب بصرياً على الخط المضمَّن). **لا يتحقق** من المعنى والنطق: `needs_human_review` يسرد ما ينتظر توقيع معلّم، وتقرير QA يبقيه في `needs_human` حتى يُوقَّع.
**التوقيع الجماعي (أسهل):** `python -m studio review export --out review.xlsx` ← افتح الملف واختر القرار (موافق/مرفوض/تعديل) ← `python -m studio review import review.xlsx --ledger review.json --reviewer "اسمك"`. «مرفوض» و«تعديل» يُستبعدان من الدروس.
**التوقيع الفردي:** `python -m studio review record --ledger review.json --kind word --text "بَاب" --reviewer "اسم المعلمة"` — أو `--verdict rejected` لاستبعاد الكلمة.
**المدة:** `target_seconds` بسماحية 10%؛ لا يُقصَّر النص ليلائم المدة بل تُضبط الأمثلة والتكرارات.

## ملفا التعريف (3.1)
| | `preschool` (4–6، الافتراضي في سطر الأوامر) | `standard` (6–9) |
|---|---|---|
| المدة الافتراضية | 180ث ±10% (2:42–3:18) | بلا هدف ما لم يُحدَّد |
| الأمثلة لكل موضع | 1–2 (يختار ما يلائم المدة) | 2–3 |
| الكلمة | «بَيْت. قُولُوا مَعِي: بَيْت.» + وقفة ثابتة 2.5ث + بطاقة «قولوا معي» | «بَيْت: الحرف في أول الكلمة» + وقفة نسبية |
| شرح الاتصال | مرة لكل موضع | لكل مثال |
| الشدة | مستبعدة من الأمثلة والقراءة والسكون والمشتتات؛ الجملة قد تحويها (لام شمسية) مع تحذير `sentence_has_shadda` | مسموحة، وتُقطَّع صحيحاً |
| المقاطع | الحركات القصيرة الثلاث فقط، بلا سكون | القصيرة والمدود والسكون |
| التمرين | 4 أسئلة | 4 أسئلة |

**أنواع التمرين الأربعة:** `which_starts_with` (أي كلمة تبدأ بالحرف)، `where_in_word` (أين الحرف)، `sound_choice` (أي مقطع سمعتم — لا يُكتب المقطع على السبورة ولا في الترجمة عبر `caption_text`)، `find_letter` (أي هذه هو الحرف — مشتتات من `SIMILAR`: حروف متشابهة الرسم). موضع الإجابة الصحيحة يتغيّر حتمياً من حرف لآخر. خيارات الحروف والمقاطع تُرقَّم ١ ٢ ٣ لا أ ب ج.

**حدود معروفة:** ترتيب الحروف المدرَّسة (`--taught`) لم يُربط بعد بمنهج محدد، لذا يظهر تحذير `no_readable_words_with_taught_letters` وتُستعمل كلمات الدرس للقراءة. الصور ما زالت أماكن محجوزة.
