# بطاقة الشخصية

احفظ لكل شخصية ملفاً في `characters/<id>.json` (أو .md) بالحقول التالية، واستخدم المعرّف نفسه في السيناريو الرئيسي.

```json
{
  "id": "teacher",
  "name": "الأستاذ سامي",
  "role": "يشرح القاعدة ويصحّح الأخطاء",
  "gender": "m",
  "appearance": {
    "shape": "رجل في الأربعينيات، نظارات مستديرة",
    "colors": ["#1F4E79", "#F2C94C"],
    "clothing": "قميص أزرق، سترة رمادية"
  },
  "expressions": ["محايد", "مبتسم", "متفاجئ", "مشجّع"],
  "voice": {
    "style": "هادئ واضح، فصحى مبسطة",
    "speed": "متوسط",
    "tts_voice": "يُحدَّد بعد اختبار الأدوات المتاحة"
  },
  "motion_style": "حركات يد هادئة، يشير إلى السبورة",
  "generation_prompt": "وصف ثابت يُعاد استخدامه حرفياً عند كل توليد",
  "reference_images": ["characters/teacher_ref_front.png"],
  "locked": true
}
```

## قواعد
- الشخصيات المرسومة فعلاً في القالب ومواضعها وجنسها في `engine/capabilities.json`. اسم الشخصية وخطابها يطابقان جنس رسمها (الطالبة أنثى).
- بعد اعتماد المشهد التجريبي اجعل `locked: true`؛ أي تغيير بعدها يستدعي مراجعة كل مشاهد الشخصية.
- أعد استخدام `generation_prompt` والصور المرجعية في كل توليد للحفاظ على الاتساق.
- يجوز تمثيل المفاهيم (الضمة، الفتحة…) بشخصيات مرحة، لكن لا تجعل التمثيل بديلاً عن الكتابة اللغوية الصحيحة.
- لا تضمّن نصاً عربياً داخل صور الشخصيات.
