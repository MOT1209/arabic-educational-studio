# تخطيط سلسلة

متى: الدرس فيه أكثر من مفهوم (إنَّ وأخواتها كلها، الهمزة بأنواعها)، أو طلب المستخدم سلسلة.

## الخطوات
1. **قسّم بالمفهوم لا بالمدة:** فيديو لكل مفهوم قابل للاختبار. مثال «إنَّ وأخواتها»:
   1) إنَّ: تنصب الاسم وترفع الخبر ← 2) أنَّ ومعناها وموضعها ← 3) كأنَّ ولكنَّ ← 4) ليتَ ولعلَّ ← 5) مراجعة وتمرين شامل.
2. **رتّب بالمتطلبات:** لا يظهر في فيديو مصطلح لم يُشرح في فيديو سابق أو في المتطلب المعلن.
3. **ثبّت عناصر السلسلة** في `project-config.json`: الشخصيات وبطاقاتها، ألوان الوظائف النحوية، خط العرض، المقدمة والخاتمة، صيغة العنوان.
4. **ملخص لكل فيديو** (`video-brief.json`) يرث من السلسلة ولا يكررها.
5. **مقاطع قصيرة مشتقة** من كل فيديو (مشهد قاعدة + مثال + سؤال) بدل كتابتها منفصلة.

## `project-config.json` (مقترح)
```json
{
  "version": "1.0.0",
  "series": "إنَّ وأخواتها",
  "audience": "preteen",
  "color_roles": {"اسم إنَّ": "#1f6feb", "خبر إنَّ": "#1a9850"},
  "characters": ["teacher", "student", "inna"],
  "videos": [
    {"id": "video-01", "topic": "إنَّ", "status": "منشور"},
    {"id": "video-02", "topic": "أنَّ", "status": "سيناريو معتمد"}
  ]
}
```

## تنبيهات
- اعتمد الفيديو الأول كاملاً قبل كتابة سيناريوهات البقية؛ دروسه تغيّر الباقي.
- لا تَعِد بإنتاج السلسلة كلها في جلسة واحدة إن كانت طويلة؛ اقترح دفعات.
- الخاتمة تحيل إلى الفيديو التالي بجملة، لا بتلخيص طويل.
