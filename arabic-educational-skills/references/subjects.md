# فروع اللغة العربية المدعومة

المهارة غير محصورة بهذه القائمة؛ عالج أي موضوع عربي تعليمي.

| الفرع | موضوعات |
|---|---|
| النحو | المبتدأ والخبر، الفاعل والمفعول به، المرفوعات والمنصوبات والمجرورات، إنَّ وأخواتها، كان وأخواتها، الجملة الاسمية والفعلية، الإعراب وعلاماته |
| الصرف | الجذر والوزن، تصريف الأفعال، المجرد والمزيد، المشتقات، اسم الفاعل والمفعول |
| الإملاء | الهمزة، التاء المربوطة والمفتوحة، الألف اللينة، علامات الترقيم |
| القراءة والفهم | القراءة الصحيحة، تحليل النصوص، استخراج الأفكار، المفردات والاستنتاج |
| الكتابة والتعبير | تكوين الجمل، بناء الفقرات، التعبير الكتابي، كتابة القصص |
| البلاغة والأدب | التشبيه والاستعارة والكناية، المحسنات البديعية، الشعر والنثر، تحليل النصوص |
| الأصوات والمفردات | مخارج الحروف وصفاتها، النطق الصحيح، المرادفات والأضداد |

## أنماط شرح مناسبة لكل فرع
- **نحو:** قبل/بعد + تلوين الوظائف + مقارنة بصرية للعلامات.
- **صرف:** تفكيك الكلمة إلى جذر ووزن بحركة بصرية (أحرف تنزلق إلى قالب الوزن).
- **إملاء:** عرض الخطأ الشائع ثم التصحيح، مع قاعدة قصيرة قابلة للحفظ.
- **بلاغة:** النص الموثق ثم تفكيك الصورة (المشبّه، المشبّه به، وجه الشبه).
- **أصوات:** رسم مخرج الحرف مع التسجيل الصوتي الصحيح.
